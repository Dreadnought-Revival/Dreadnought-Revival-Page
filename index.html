01 // Mission Briefing

The Mission: Bring Her Back

Dreadnought was a massive-scale space combat game — dreadnoughts, cruisers and fighters clashing across open maps — shut down with its publisher. This project is a fan-led revival: a community-operated private server that runs the completely unmodified game client against our own backend.

Everything is emulated server-side — login, hangar, inventory, market, loadouts, career progression and matchmaking. The only thing a player installs is a replacement launcher that signs them into our servers. No game files are modified, and no game code or assets are distributed here.

Operators can additionally host matches themselves: the server stack spawns headless dedicated battle servers, one per match.

> objective: preserve a piece of online-game history — playable, forever.
  • Dreadnought-Revival-server backend services, battle-server mod, data and docs
  • Dreadnought-Revival-Launcher the Windows launcher — the only thing a player installs
  • Dreadnought-Revival-Page this website

Fan-run project, not affiliated with Greybox or Yager. Dreadnought and all related assets belong to their respective owners. You need your own copy of the game client (Steam App 835860).

05 // Mission Timeline

The Road Back to War

Phase 01 — Complete

Client Reverse Engineering

Hooked and decoded the UE4 client's binary protocol, catalog and session flows — building on the original Dreadnought Revival Patch SDK. Every server payload is traceable to the client's own tables.

Phase 02 — Complete

Backend Emulation

Multiple Go microservices reimplement the Greybox/Yager backend: registration, profiles, inventory, market, fleets, matchmaking and the Firmament social socket.

Phase 03 — Complete

Replacement Launcher

dn-launcher.exe (Windows) plus a Linux/Proton wrapper: sign-in, CA install without admin rights, news tiles, and one-click Play into the unmodified game.

Phase 04 — Complete

Dedicated Battle Servers

game-manager / dn-dedicated spawns headless battle servers per match with a managed UDP port pool, readiness gating and per-instance logs. The battle-server mod supplies host loadouts.

Phase 05 — In Progress

Public Playtests

Community alpha playtests: matchmaking auto-scaling, Havoc wave defence rebuilt by the battle-server mod, conquest and Onslaught modes, contract and XP economies being tuned live.

Phase 06 — Queued

Full Release

Tech tree and daily contracts fully unlocked, storefront artwork restored, stable public deployment with documented one-command setup for new operators and players.

06 // Join the Fight

How to Play & Contribute

Get In-Game (Players)

01

Own the game

You need your own copy of Dreadnought on Steam (App 835860). No game files are distributed by this project.

02

Get the launcher

Grab the latest release of dn-launcher.exe from the launcher repository's releases:

github.com/Dreadnought-Revival/Dreadnought-Revival-Launcher/releases
03

Run the launcher and register

Create an account in the launcher, install the server certificate when prompted — the launcher handles it without admin rights.

04

Sign in & play

Hit PLAY, queue for a match and fly. Linux players use the bundled Proton/Wine wrapper script.

Contribute (Developers)

This is a server for a client we cannot change — never invent data: everything the server sends must be traceable to the client's own tables or binary. Read the client's parsers before forming a theory.

  • The server repository carries the backend, the battle-server mod, data and docs.
  • The launcher repository holds the Windows launcher and its releases.
  • This site lives in Dreadnought-Revival-Page — content fixes and style tweaks via pull requests.

Testers, bug reporters and Discord regulars keep the servers alive — every playtest report matters.
