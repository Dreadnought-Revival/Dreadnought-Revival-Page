About the project

Dreadnought Revival runs a private server for Dreadnought (Unreal Engine 4, Steam App 835860), which was shut down by its original publisher. The goal is to keep the unmodified game client playable: everything the game expects from the official backend — login, hangar, inventory, market, loadouts, career progression and matchmaking — is emulated server-side by our own services.

The only thing a player installs is a replacement launcher that points the game at our servers. The project is split across three repositories:

  • Dreadnought-Revival-server backend services, battle-server mod, data and docs
  • Dreadnought-Revival-Launcher the Windows launcher — the only thing a player installs
  • Dreadnought-Revival-Page this website

Disclaimer: this is a fan-run project, not affiliated with Greybox or Yager. Dreadnought and all related assets belong to their respective owners. You need a legitimate copy of the game client (Steam App 835860).

How to join

  1. Get the game client. Install Dreadnought (Steam App 835860) in Steam as usual — the client itself is not modified.
  2. Download the launcher. Grab the latest release from Dreadnought-Revival-Launcher.
  3. Run the launcher and register. The launcher signs you in and starts the game pointed at the Revival servers.
  4. Play. Queue for a match from the in-game matchmaking — the backend handles the rest.

Server operators: see the server repository for build and run instructions.
